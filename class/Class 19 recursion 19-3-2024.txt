Recursion - If you have a senerio where you can express a bigger problem in terms of smaller same problem then its is case for recursion.

find sum of n numbers

function sum(n)
{
if(n==1)
{
    return 1;
}
else 

{
    return sum(n-1)+n;
}
}
console.log(sum(5));

output - 15
